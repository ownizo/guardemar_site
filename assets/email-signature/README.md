# Hugo Gonçalves email signature

Open `guardemar-hugo-goncalves.html` in a browser and copy the rendered signature, rather than copying the HTML source. Send a test email to yourself after installation to check spacing and links. An optional `guardemar-hugo-goncalves-with-logo.html` version uses the production-hosted logo while retaining all contact details as text; the text-only version is the most dependable across email clients.

## Gmail

Open **Settings → See all settings → General → Signature**, create a new signature, then paste the rendered signature into the editor. Choose it for new emails and replies if required.

## Apple Mail

Open **Mail → Settings → Signatures**, add a signature to the relevant account, then paste the rendered signature. Disable “Always match my default message font” if Mail overrides the design.

## Outlook

Open **Settings → Accounts → Signatures** in new Outlook, or **File → Options → Mail → Signatures** in classic Outlook. Create a signature and paste the rendered version into the editor.

The signature is text-based, so all essential contact details remain visible when remote images are blocked.
